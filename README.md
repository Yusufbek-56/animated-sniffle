# Офлайн-карты Узбекистана

| Файл | Что это |
| --- | --- |
| `constructor.html` | Конструктор карт, 54 МБ. Все данные OpenStreetMap уже внутри: выбираешь область и слои, видишь размер в МБ, получаешь один HTML-файл. Интернет не нужен. |
| `uzbekistan.html` | Готовая карта всей страны, 56 МБ: здания, улицы, дороги, железные дороги, поиск, маршруты для машин и поездов. |
| `uzmap-sw.js`, `uzmap.webmanifest`, `uzmap-icon.png` | Служебные файлы для работы без интернета и установки на экран «Домой». |
| `poputchik.html` | Отдельное приложение «Попутчик»: приборы для поездки. Работает и без карты, а с файлом карты показывает её. Рядом лежат его служебные файлы `poputchik-*`. |

## На iPhone

Предпросмотр в приложении «Файлы» не запускает JavaScript (по отзывам пользователей, на устройстве не проверено).
Поэтому там карта показывается как SVG-картинка: масштаб щипком, без поиска и маршрутов.
Конструктору и маршрутам нужна страница по HTTPS в Safari.

Есть два пути:

1. **С интернетом, прямо сейчас:** [конструктор на claude.ai](https://claude.ai/artifact/WJd31NCXiEowAzfGzjFWX6). Нужен вход в claude.ai, ссылка видна только владельцу. Здесь нет работы без интернета и GPS: их блокирует песочница страницы.
2. **Без интернета и с GPS:** GitHub Pages, адрес `https://yusufbek-56.github.io/animated-sniffle/constructor.html`. Для Pages репозиторий должен быть публичным или на платном тарифе, а сейчас он приватный. Файлы уже лежат в ветке `gh-pages`. Если сайт не открывается, проверь Settings → Pages: источник `gh-pages`, папка `/ (root)`.

После первого открытия по адресу Pages страница сохраняется и дальше работает без интернета. Лучше добавить её на экран «Домой»: иначе iOS может стереть сохранённое после нескольких дней без использования.

## На компьютере

Скачай `constructor.html` и открой двойным щелчком. Сервер не нужен.
